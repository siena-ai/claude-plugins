# Siena plugins for Claude

Plugins that connect Claude to [Siena](https://siena.cx).

| Plugin | What it does |
|---|---|
| [`siena`](./siena) | The Siena connector plus skills for conversation analytics, Siena's features and apps, and the Shopping Agent |

To connect Siena to Claude on the web or desktop, see [CONNECTOR.md](./CONNECTOR.md).

Install in Claude Code:

```
/plugin marketplace add siena-ai/claude-plugins
/plugin install siena@siena
```
